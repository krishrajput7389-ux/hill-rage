# Hill Rage - Physics Driving Game 

A coooool 2D physics-based endless driving game built from scratch using **Godot 4**. 


##  Features
* **Real life based physicsss**
* **Infinite track for your swag**
* **Real enginnnneee soundss**
* **Announce yourself after every 1000m**

##  Tech Stack
* **Game Engine:** 
* **GDScript** 
* **HTML5** 

##  How to Play

**Drive as far as you can without flipping your car.** 

### Controls:
*   **Accelerate / Lean Forward:** Press `D` or `Right Arrow` 
*   **Brake / Reverse / Lean Back:** Press `A` or `Left Arrow`
